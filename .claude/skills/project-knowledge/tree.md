## Crates

| Crate | Purpose | Top-level modules |
|---|---|---|
| `openflow-audio` | Microphone capture (cpal), resampling to 16 kHz mono, rolling ring buffer with pre-roll, and (Prompt 4) Silero voice activity detection. | `engine.rs`, `fake.rs`, `lib.rs`, `resample.rs`, `ring.rs`, `source.rs`, `vad.rs` |
| `openflow-context` | Context awareness (design doc §7): who has focus, what kind of app it is, what tone the cleanup LLM should use, and (best-effort) nearby text via platform accessibility APIs. | `lib.rs`, `profiles.rs`, `win_focus.rs`, `win_uia.rs` |
| `openflow-core` | Session orchestration: the single-threaded event loop and state machine that owns a dictation session end to end (idle → recording → transcribing → injecting). | `finalizer.rs`, `lib.rs`, `orchestrator.rs`, `partial.rs` |
| `openflow-hotkey` | Global hotkey listening via low-level keyboard hooks. | `lib.rs`, `parse.rs`, `tracker.rs`, `windows_hook.rs` |
| `openflow-inject` | Text injection into the focused application. | `fake.rs`, `lib.rs`, `win_clipboard.rs`, `win_keystroke.rs` |
| `openflow-llm` | Language-model access: the `LlmBackend` trait, Ollama client, per-task model routing, the dictation-cleanup prompt, and the output guard. | `backend.rs`, `cleanup.rs`, `command.rs`, `guard.rs`, `lib.rs`, `ollama.rs`, `router.rs` |
| `openflow-models` | Model management: STT/VAD model registry, checksummed + resumable downloads into the app data dir, and Ollama model presence checks. | `download.rs`, `lib.rs`, `ollama.rs`, `registry.rs` |
| `openflow-postproc` | Deterministic post-processing that runs before/around the LLM. | `casing.rs`, `dictionary.rs`, `lib.rs`, `snippets.rs` |
| `openflow-settings` | Typed configuration: schema, defaults, atomic persistence, versioned migrations, and hot reload. | `io.rs`, `lib.rs`, `migrate.rs`, `schema.rs`, `watch.rs` |
| `openflow-store` | Local SQLite persistence: dictation history (content only — never screen context, design doc §7), personal dictionary, snippets, custom commands, and latency timings. | `lib.rs` |
| `openflow-stt` | Speech-to-text: the `SttEngine` trait and backends (whisper.cpp now, Parakeet TDT via ONNX in Prompt 10) plus, later, streaming partial policies. | `fake.rs`, `lib.rs`, `whisper.rs` |
